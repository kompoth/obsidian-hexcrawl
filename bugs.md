## Border tool bugs

1. No segment deletion tool. While editing existing or creating a new border, RMC on an edge must remove it.
2. When editing a border, point denoting a possible new segment is rendered under other layers, making it impossible to click on some point if they are covered by overlying layer elements.
3. It is possible to add an edge outside of the map boundaries.
4. No real way to control, which hex will be the first one when adding the first edge of a new border. It must work like this: if user clicks near the edge closer to one hex, this hex is the first one.
